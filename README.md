# ZAKLADKA

Вкладки вместо вкладок: ссылки складываются в раскрывающиеся папки-списки,
таскаются мышью между ними и открываются по клику. Чтобы не держать в Chrome
полсотни вкладок ради «потом посмотрю».

**Сайт:** https://vzavalko.github.io/zakladka/

С расширением появляется полоса открытых вкладок: перетащил карточку в папку —
ссылка сохранилась, вкладка в браузере закрылась. Удалённое лежит в корзине 30
дней, повторы ловятся при добавлении, а запасную копию ссылок держит у себя
расширение — на случай очистки данных сайта.

## Что это

Одна HTML-страница без сборки, без зависимостей и без сервера. Данные лежат
в `localStorage` этого браузера и никуда не уходят — ни в репозиторий, ни на
чью-то сторону. Обратная сторона: между устройствами они не ездят, для переноса
есть выгрузка и загрузка JSON в меню `⋯`.

## Как класть сюда ссылки

- **Перетащить значок слева от адреса** в адресной строке Chrome — прямо на нужную
  папку. Так приезжает настоящий заголовок страницы.
- **Скопировать ссылку на странице и нажать `⌘V`** — вместе со ссылкой приедет её текст.
- **`⌘V` с голым адресом.** Для YouTube, Vimeo, SoundCloud, Flickr и TED название
  подтянется из сети само (эти сервисы отдают oEmbed всем). Для остальных соберётся
  из адреса: `/kak-my-delali-sajt/` → «Как мы делали сайт».
- **Расширение Chrome** — [vzavalko/zakladka-extension](https://github.com/vzavalko/zakladka-extension):
  сдаёт открытые вкладки пачкой с настоящими заголовками и закрывает их, умеет узнать
  название по любому адресу и подменяет страницу новой вкладки. На расширение
  ограничения браузера не распространяются, поэтому названия оно достаёт для всего.

## Горячие клавиши

`/` поиск · `N` добавить · `F` новая папка · `E` свернуть или раскрыть всё
`⌘V` вставить адреса · `⌘Z` отменить · `Esc` закрыть

## Значки сайтов

Берутся по цепочке: сначала `icons.duckduckgo.com`, если не отдал — `favicon.ico`
самого сайта, если и его нет — плитка с буквой домена. То есть список доменов
из вашей картотеки видит DuckDuckGo. Выключается в меню `⋯` → «Выключить значки
сайтов», тогда везде остаются буквы и никаких внешних запросов.

## Разработка

```bash
python3 -m http.server 8801   # и открыть http://127.0.0.1:8801/
```

Правки — в `index.html`, он же и есть всё приложение. Публикация: пуш в `main`,
GitHub Pages отдаёт ветку из корня.
