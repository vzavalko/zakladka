# ZAKLADKA — рабочие заметки для агента

Одностраничное приложение для ссылок: раскрывающиеся папки-списки в духе Toby.
Всё в `index.html` — ни сборки, ни зависимостей, ни сервера. Публикуется на
GitHub Pages: пуш в `main` → https://vzavalko.github.io/zakladka/

Рядом живёт расширение Chrome: `../zakladka-extension`,
[vzavalko/zakladka-extension](https://github.com/vzavalko/zakladka-extension).

## Откуда взялось и куда нельзя возвращаться

Сначала это был артефакт Claude (`claude.ai/artifact/6cbHdWZQYLRpe7sW6kbeab`,
там лежит копия данных на момент переезда). Переехали, потому что песочница
артефакта режет то, ради чего сервис существует:

- `default-src 'none'` — **никаких картинок с чужих доменов**, поэтому фавиконки
  там невозможны в принципе;
- **никаких сетевых запросов** — значит, ни названия страниц, ни oEmbed;
- страница живёт на служебном домене, к которому не подключиться расширением.

Проверено при переезде: `claude.ai` отдаёт `x-frame-options: SAMEORIGIN`, то есть
**встроить ZAKLADKA во фрейм нельзя** — страница новой вкладки в расширении
именно переадресовывает, а не показывает копию.

## Что можно и чего нельзя из браузера

CORS никуда не делся и на своём домене: **прочитать произвольную страницу нельзя**.
Работает только то, что сервис разрешает всем:

- **oEmbed** (`OEMBED` в коде) — YouTube, Vimeo, SoundCloud, Flickr, TED отдают
  название кому угодно. Проверено живым запросом, названия настоящие.
- **картинки** — фавиконки грузятся цепочкой: `icons.duckduckgo.com` → `favicon.ico`
  самого сайта → плитка с буквой. Загрузившийся значок вешает на плитку класс
  `has-icon`: она становится белой с ровной обводкой, иначе цветная подложка под
  буквой лезет рваной каймой по скруглениям.

  Удачные адреса значков лежат в `zakladka.favs` (`iconSrc`), и класс
  `has-icon` проставляется **в разметке**, а не по `onload`. Иначе каждая полная
  перерисовка — а она полная даже при развороте папки — создавала новые `<img>`,
  и все плитки разом моргали буквой, прежде чем побелеть. По той же причине у
  известного значка нет `loading="lazy"`, зато есть `decoding="sync"`.

  Неудачи держим только в памяти сессии (`iconBad`). Записывать их в
  `localStorage` нельзя: если DuckDuckGo прилёг, весь список навсегда останется
  буквами. `load` и `error` не всплывают — слушатели на `document` в фазе
  перехвата.

Для остальных сайтов название достаёт **расширение** через мост (ниже) — у него
ограничений нет.

## Имена ссылок

`deriveTitle(url)` собирает имя из адреса: правила для полутора десятков сайтов
плюс общий разбор пути с отсечением идентификаторов (`looksId`), числовых
префиксов и служебных кусков (`GENERIC`). Возвращает `{title, weak}`.

`weak: true` значит «из адреса ничего не вытащить». Такую одиночную ссылку
`finishAdd` ставит на переименование сразу, с выделенным текстом. Порядок в
`finishAdd`: oEmbed → расширение → предложить вписать руками.

Приоритет всегда у пришедшего названия: из перетаскивания (`text/html`), из буфера
(строка `Заголовок | адрес` — разделителем считается **последняя** ` | ` перед
адресом, иначе дефисы внутри названия превращаются в кашу) или от расширения.

## Мост с расширением

`postMessage` в пределах своего окна, `targetOrigin = location.origin`.

| сообщение | кто шлёт | смысл |
| --- | --- | --- |
| `{zakladka:'hello'}` | расширение | подключилось, можно спрашивать |
| `{zakladka:'resolve', id, urls}` | страница | узнай названия |
| `{zakladka:'resolved', id, items}` | расширение | ответ |
| `{zakladka:'push', items, folder, newFolder}` | расширение | вот вкладки, положи их. `folder`: id папки, `''` — без папки, `'@at'` или ничего — куда складываем сейчас, `'@new'` — папка с именем `newFolder` (найти или завести) |
| `{zakladka:'snapshot', folders, at, urls}` | страница | снимок для попапа расширения: ответа не ждёт |
| `{zakladka:'tabs', id}` | страница | что сейчас открыто в этом окне |
| `{zakladka:'tabs-list', id, items}` | расширение | список; с `id: 0` — сам прислал, потому что что-то изменилось |
| `{zakladka:'close', id, ids}` | страница | закрой эти вкладки |
| `{zakladka:'closed', id, closed}` | расширение | сколько закрыл |
| `{zakladka:'alive', id, urls}` | страница | проверь, отвечают ли адреса |
| `{zakladka:'alive-done', id, denied, items}` | расширение | ответ либо отказ без разрешения |
| `{zakladka:'backup', id, json, links, force}` | страница | положи копию у себя |
| `{zakladka:'backup-done', id, saved, at}` | расширение | положил или отказался (чаще раза в сутки не пишет) |

Вопрос → ответ склеиваются по `id`; ответы разбирает таблица `REPLY`, ждёт
`askExt()`. Без ответа в срок обещание отпускается само — иначе вызывающий
завис бы навсегда. `snapshot` ответа не ждёт вовсе: в `bridge.js` он лежит в
отдельной таблице `TELLS`.

**Снимок для попапа.** В окне у значка расширения есть выбор папки, но папки
живут в `localStorage` страницы, а у попапа свой origin. Поэтому `persist()`
зовёт `sendSnapshot()` — с задержкой 400 мс, чтобы серия правок не превратилась
в серию писем, — и шлёт папки, активную папку и нормализованные адреса всех
ссылок. По ним попап сам предупреждает о повторе: иначе вопрос «добавляем
снова?» открылся бы в фоновой вкладке, незамеченным.

`snapTimer` объявлен через `var`, а не `let`: `persist()` вызывают и до того,
как выполнится кусок кода с мостом, — `let` дал бы ошибку временной мёртвой
зоны.

**Папка по имени.** Расширение не умеет заводить папки — оно до картотеки не
дотягивается, — поэтому присылает имя, а `folderByName()` находит или создаёт.
В `addLinks()` папка может прийти **функцией**: её вызывают уже после
`pushUndo()`, иначе отмена вернула бы состояние с пустой новой папкой.

**Чужая папка не меняет активную.** Обычное добавление переносит `ui.at` туда,
куда положили («дальше вставлять будем сюда же»). Для `push` с явной папкой это
неверно: человек выбирал активную руками, а из попапа сохранял мимоходом, —
поэтому обработчик возвращает `ui.at` на место.

Ключ сообщения раньше назывался `kartoteka`. Обе стороны понимают оба имени и
подписывают свои письма сразу двумя (`MARK` и `MARK_OLD`) — иначе установленное
расширение перестало бы понимать обновившуюся страницу. Когда всё обновится,
вторую подпись можно убрать. Мост подключается на `vzavalko.github.io/zakladka/*`
и на старый адрес. Буфер обмена
остаётся запасным путём и не зависит ни от домена, ни от разрешений.

## Хранение

`localStorage`, ключи `zakladka.v1` (данные), `zakladka.ui` (вид, активная
папка, открыта ли полоса вкладок), `zakladka.favs` (кеш адресов значков).

Проект раньше назывался «Картотека», ключи были `kartoteka.*`. Переезд делает
`migrateKeys()` в начале скрипта: копирует старые ключи в новые при первом
открытии и старые **не удаляет** — запасной выход, если что-то пойдёт не так.

Сам адрес сайта на данные не влияет: `localStorage` привязан к источнику
(схема + домен + порт), путь в него не входит. Поэтому переезд с
`github.io/kartoteka/` на `github.io/zakladka/` ничего не стёр, и на всех
страницах `vzavalko.github.io` хранилище общее — отсюда и приставка в ключах.
Сервера нет, между устройствами не ездит — выгрузка в JSON не украшение, а
единственная резервная копия.

**Активная папка** — `ui.at`, туда попадает вставленное. Задаётся кликом по шапке
папки и любым добавлением; помечена серой обводкой счётчика — цветная заливка
спорила с акцентом кнопки «Ссылка». Не была нужна в
раскладке-аккордеоне, пока всё не валилось во «Без папки».

**Две открытые вкладки ZAKLADKA.** Хранилище общее, состояние в памяти у
каждой своё, а `persist()` пишет его целиком — раньше последняя записавшая
вкладка затирала всё, что сделали в другой (а расширение отдаёт ссылку только
одной). Теперь чужую запись ловит событие `storage`: `flushHeldRemote()`
подменяет `state`, перерисовывает и **чистит undo** — снимки целиком вернули бы
и чужие правки.

- Посреди правки на месте и перетаскивания запись ждёт в `heldRemote`.
- При завершении чужое применяется **первым**, своё — поверх. Поэтому колбэки
  `editInline` ищут ссылку по id (`renameLink`), а `onUp` зовёт `endDrag()` до
  `applyDrop()`. Держать в колбэке старый объект нельзя: правка уйдёт мимо.
- `moveLink`/`moveFolder` отказываются нести в папку, которой уже нет.
- Проверено двумя вкладками в изолированном контексте chrome-devtools-mcp.

## Раскладка и перетаскивание

Одна колонка во всю ширину, отступ 22px одинаковый у логотипа, карточек и справа.
Сетка ссылок: 5 колонок на десктопе, дальше 4 / 3 / 2 / 1 по медиазапросам.

Перетаскивание — **на pointer-событиях, не HTML5 drag**. Так надёжнее и не спорит
с приёмом ссылок из браузера (внешний drop остаётся на `dragover`/`drop`).
Порог 5px мышью, долгое нажатие 320мс пальцем. Свёрнутая папка раскрывается сама,
если подержать над ней. `justDragged()` гасит клик 160мс после переноса — тесты,
кликающие сразу после переноса, на это натыкаются.

## Проверка в панели браузера

- **Пока панель скрыта, `requestAnimationFrame` замирает** — отложенные действия
  (переименование после вставки) срабатывают только при следующем обращении к
  странице. Делайте `computer screenshot` первым действием в `browser_batch`.
- Нативные `confirm`/`prompt` не годятся, в коде свои листы (`ask()`).
- Синтетический клик по карточке дописывайте `pointerup`.
- Проверять `deriveTitle` удобнее, вытащив её из исходника и запустив отдельно, —
  иначе мешают асинхронные подмены названий.

## Полоса открытых вкладок

Кнопка с раскрытой книгой в шапке. Список приносит расширение: браузер
странице про чужие вкладки ничего не рассказывает. Перетащили карточку из
полосы в папку — ссылка добавилась, а вкладка в браузере закрылась; это и есть
смысл затеи, поэтому `takeTabs()` шлёт `close` **после** успешного добавления.
Отказались на вопросе про повтор — вкладка остаётся открытой.

- Перетаскивание — тот же механизм, что у карточек, третий вид `dnd.kind`
  (`'tab'`). Разница в приземлении: ссылки ещё нет, поэтому сначала
  `addChecked()`, потом `placeAt()` ставит её на место, куда уронили.
- Сама полоса целью не бывает: `hitTest` отсекает `#tabs` в начале, иначе
  карточка, брошенная мимо, уезжала бы в корень.
- Список обновляется сам: расширение шлёт `tabs-list` с `id: 0` на каждое
  изменение вкладок. Без этого полоса врала бы про уже закрытые.
- Открыта она или нет — в `zakladka.ui` (`tabs`). Пишет `saveUi()`, и зовут её
  как `render()`, так и `toggleTabs()`: переключение полосы само по себе
  перерисовку не вызывает.

## Раскрытие папок

Плавное, и это диктует устройство отрисовки.

- **Тело папки всегда в разметке**, даже у свёрнутой. Иначе анимировать нечего:
  `renderCol()` собирает колонку заново, и новый элемент рождался бы сразу в
  конечном виде — переход CSS на такое не запускается. Плата: карточки всех
  папок висят в DOM, значит и значки сайтов грузятся сразу.
- **Клик по шапке колонку не перерисовывает.** `toggleFolder()` меняет
  состояние и переключает класс на живом элементе (`showFolder()`), после чего
  зовёт `persist()` — запись на диск без отрисовки. `commit()` = `persist()` +
  `render()`; если нужного элемента на экране нет, откат на `commit()`.
  По той же причине отметку активной папки переставляет `markTarget()`, а не
  перерисовка: клик делает и то, и другое разом.
- Едет **строка сетки** `0fr → 1fr`: до `height: auto` анимацией не добраться,
  а замерять высоту скриптом не хочется.
- Внутри сетки — пустой `.sec-clip`, и только в нём `.sec-body` с полями. При
  `border-box` элемент не может стать ниже собственных полей, поэтому свёрнутая
  папка без этого слоя оставляла полоску в 18px.
- `.sec-clip` вдобавок `visibility: hidden` с задержкой ровно в длину
  схлопывания: содержимое не пропадает раньше времени, но свёрнутое не ловит ни
  Tab, ни `elementFromPoint` — а от последнего зависит выбор цели при
  перетаскивании.

## Горячие клавиши

`⌘F` — поиск, `⌘⇧L` — добавить ссылку, `⌘⇧F` — новая папка, `⌘⇧O` — полоса
вкладок, `⌘⇧E` — свернуть или раскрыть всё. Плюс `⌘V`, `⌘Z`/`⌘⇧Z` и `Esc`.

Раньше это были одиночные буквы (`N`, `F`, `E`, `/`) — срабатывали от любого
нажатия мимо поля ввода и не работали в русской раскладке.

Сверяем `e.code`, а не `e.key`: под `⌘` в русской раскладке в `e.key` приезжает
кириллица, а `e.code` одинаков в любой. `⌘Z` внутри поля ввода пропускаем
браузеру — там он должен отменять набор, а не состояние картотеки.

Выбор сочетаний ограничен тем, что занял Chrome. `⌘T`, `⌘N`, `⌘W`, `⌘L`
страница перехватить не может вовсе. `⌘⇧O` на Windows — менеджер закладок, но
на macOS свободно.

## Тема

Светлая по умолчанию, тёмная — только кнопкой в шапке (солнце/луна справа от
книги). Системную настройку **не слушаем**: пользователь просил светлую по
умолчанию. Выбор лежит в `zakladka.ui` (`theme`).

- Тёмная — сине-серая в духе ночной темы Telegram, не чёрная: `--bg` #0E1621
  (фон и шапка), `--paper` #17212B (карточки, меню, окна, полоса вкладок),
  `--surf`/`--surf-2` выше по ступеням. Все серые одного оттенка ≈212°.
  Маджента `#FA0CF7` не меняется ни в одной теме.
- `--bg` и `--paper` в светлой совпадают, в тёмной — нет. Фон страницы —
  `--bg`, всё, что лежит поверх, — `--paper`. Путать нельзя: карточки сольются
  с фоном.
- Отдельные токены там, где инверсия ломала вид: `--toast`, `--scrim`,
  `--knob` (пилюля переключателей), `--fav-bg` (подложка значков сайтов —
  светлая и в темноте: чёрные значки иначе пропадут), `--panel`/`--panel-card`.
- Тема ставится **скриптом в `<head>`** до стилей — иначе тёмная мигала бы
  светлой. Смена — через View Transitions (растворение), без него — мгновенно.
- `setTheme()` меняет `ui.theme` **до** перехода: колбэк `startViewTransition`
  асинхронный, и `saveUi()` успевал записать старую тему.
- Тему видят и соседние вкладки (событие `storage` по `zakladka.ui`), и
  расширение: она едет в снимке (`theme`), попап и новая вкладка красятся так
  же.

## Прочие анимации

Тем же приёмом, что и папки: `display:none` анимировать нечем, поэтому
прячем видимостью, а разметка остаётся на месте.

- **Меню** — `visibility` + `opacity` + `scale`. Разметка на месте всегда, и
  `openMenu()` по-прежнему меряет ширину перед тем, как поставить меню.
  Закрывается оно на `pointerdown`, а открывается на `click`, поэтому повторный
  клик по той же кнопке успевал закрыть и тут же открыть заново. Лечит
  `reopenBlock`: запоминаем, кто открыл (`menuOwner`), и гасим ближайшее
  открытие от него же.
- **Окна** — затемнение по `background-color`, сам лист всплывает. `pointer-events`
  сняты у закрытого, иначе невидимый слой ловил бы клики по странице.
- **Полоса вкладок** — едет ширина, колонка раздвигается. Чтобы содержимое не
  переверстывалось на ходу, у детей своя `min-width`; фон и граница тоже на
  детях, иначе свёрнутая полоса рисовала бы полоску в 1px.
- **Переключатели вида и темы** — белая пилюля переезжает через `transform`, а не
  перекрашивается. Положение задаёт `data-v` на `#seg` и `#themeSeg`.
- **Новая карточка** — класс `fresh`, который `renderCol()` ставит один раз и
  тут же забывает: анимация уже вшита в созданную разметку.

Глобальное `prefers-reduced-motion` в конце блока стилей гасит всё разом —
отдельных проверок в каждом правиле не нужно.

## Корзина, повторы, мёртвые ссылки

**Корзина** (`state.trash`) — удалённое лежит `TRASH_DAYS` = 30 дней, просрочку
подчищает `purgeTrash()` при запуске. Отмена живёт только до перезагрузки, а
копии у сервиса нет, поэтому просто выбрасывать нельзя. Запись хранит **имя**
папки, а не её id: папку могли удалить, и `folderByName()` при возврате создаст
её заново.

**Повторы.** `normUrl()` приводит адрес к общему виду — без `www`, без
завершающего слэша, без якоря, — иначе защита ловила бы только совпадения
символ в символ. Любое добавление идёт через `addChecked()`, он же спрашивает
«уже есть, добавляем снова?» и называет папку, где лежит старая. Разбор
накопившегося — `dupeSheet()`, оставляет самую старую копию.

**Мёртвые ссылки.** Проверяет расширение (`alive`), страница так не может.
Помеченные получают `l.dead` и метку на карточке. Без выданного разрешения на
доступ к сайтам приходит `denied` — это не ошибка, а нормальный ответ.

## Запасная копия

`backupNow()` шлёт выгрузку расширению при первом `hello` и по пункту меню.
Расширение пишет не чаще раза в сутки (`force` обходит). Смысл — пережить
«очистить данные сайта»: `localStorage` это сметает, хранилище расширения нет.
Забрать копию можно в окне расширения, в настройках.
